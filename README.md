# بطاقة بيانات الحساب المدرسي الموحد

واجهة عربية متجاوبة للبحث عن حساب الطالب بالاسم، مع بطاقة تعرض الاسم والكود واسم المستخدم وكلمة المرور.

## مهم جدًا قبل النشر
كشف المدرسة يحتوي على بيانات دخول وكلمات مرور للطلاب. **لا ترفع `students.json` أو أي بيانات حقيقية إلى مستودع عام أو إلى كود JavaScript منشور**؛ أي شخص يستطيع تنزيلها حتى لو كانت مخفية في الواجهة. هذه النسخة تستخدم خمسة سجلات توضيحية من أول صفحة لإظهار طريقة العمل فقط، وليست قاعدة بيانات كاملة.

للنشر الحقيقي، استخدم خادمًا خلفيًا خاصًا مع صلاحيات وصول وتحقق إضافي من هوية الطالب، ولا تجعل قاعدة بيانات الحسابات ضمن ملفات GitHub Pages العامة. يفضّل تغيير كلمات المرور إذا سبق نشرها علنًا.

## تجربة محلية
1. نزّل الملفات.
2. افتح `index.html` في المتصفح.
3. جرّب أحد الأسماء الموجودة في `app.js`.

## إضافة السجلات
أضف السجلات إلى مصفوفة `students` في `app.js` بهذا الشكل:
```js
{name:"الاسم كما في الكشف", code:"رقم الكود", username:"اسم المستخدم", password:"كلمة المرور"}
```
لا تستخدم هذه الطريقة لبيانات حقيقية على موقع عام.

## رفع الواجهة على GitHub Pages (للتجربة ببيانات وهمية فقط)
1. أنشئ مستودعًا جديدًا.
2. ارفع `index.html`, `style.css`, `app.js`, و`README.md`.
3. من **Settings → Pages** اختر فرع `main` ومجلد `/(root)`.
4. احفظ وانتظر رابط النشر.
